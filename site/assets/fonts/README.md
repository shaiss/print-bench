# Archivo (variable)

The Modernist design system's one typeface, vendored so the served output
references nothing external. Variable weight 400–800, woff2, split by
unicode range exactly as Google Fonts serves it:

- `archivo-latin.woff2` — latin
- `archivo-latin-ext.woff2` — latin extended

Source: the [Archivo project](https://github.com/Omnibus-Type/Archivo)
(Omnibus-Type), served build fetched from fonts.gstatic.com (Archivo v25).
